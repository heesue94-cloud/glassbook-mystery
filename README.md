# 유리책방 · 당첨자는 사망했습니다

정적 HTML/JavaScript로 동작하는 웹 탐색 미스터리입니다. main 루트가 GitHub Pages 배포 소스입니다.

## 시작

home.html에서 출판사 공개 홈페이지를 확인합니다. 외주 개발 역할 계정은 admin / glassbook입니다. 인수인계에서 기존 기록을 살피며 사건을 발견하는 구조이며 수리 미션은 없습니다.

## 탐색과 로드맵

- 71건의 정적 접수·문의·메일·계약·수사 확인 자료와 일상 업무 자료가 있습니다.
- 문서와 실제 첨부, 같은 대화의 다른 메일은 새 탭으로 엽니다.
- 0217 최초 열람 후 우측 아래 로드맵 아이콘이 표시됩니다. 미열람 주요 자료는 ???로 숨기고, 최초 열람 때만 문서번호 수집 말풍선을 표시합니다.
- 보존 요청 W-301 최초 열람 5초 뒤 화면 흔들림·노이즈와 사건자료실 해금 안내가 나옵니다. 안내는 X로 닫습니다.
- 사건자료실은 로드맵과 외부메일 발신 진입을 제공합니다.

## 직원 및 파트너

직원 카드 아래에 협력사·외부 참조기관 배너 5개가 있습니다. 각 배너는 별도 로컬 소개 사이트로 연결됩니다. 문체부·경찰청은 게임용 재구성이며 실제 후원·제휴를 뜻하지 않습니다.

## 외부메일 발신과 결말

1. 핵심 선행 기록 19건을 읽으면 작성 창을 열 수 있습니다.
2. 다온차 소개 사이트의 고객센터에서 CS 주소를 확인합니다.
3. 외부메일 발신에서 주소를 직접 입력합니다. 일치하는 주소와 열람 조건을 충족할 때만 본문이 활성화됩니다.
4. 키 입력마다 지정 문구가 세 글자씩 표시되고, 완성 후 발송하면 다온차의 공급 확인 회신이 열립니다.
5. 회신 M-303을 직접 읽은 뒤 경찰청 재구성 사이트의 팝업 등에서 기록 접수 이메일을 확인합니다.
6. 해당 주소로 신고문을 작성·발송하면 경찰 회신 M-305가 도착합니다. 회신의 수사 시작 동의 버튼에서 마우스·터치 서명을 완료하면 11초 수사 경과 연출 후 엔딩이 열립니다. 기존 보고서 양식으로 결말을 여는 경로는 제거했습니다.
7. 엔딩에서는 원작자 표기 정정·사과문 홈페이지와 무기징역 구형 후일담 기사로 이동할 수 있습니다.

표시된 이메일은 게임 입력값이며 실제 외부 전송을 하지 않습니다. 1886은 게임 내 기록 문의용 가상 번호입니다. 실제 응급상황 안내는 119와 질병관리청 응급수칙을 구분해 표시합니다.
