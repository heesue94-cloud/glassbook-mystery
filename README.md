## 현재 버전
- 총 71건의 응모·문의·업무·메일·첨부·접수 자료.
- 일상 업무, 일반 독자 문의, 인쇄·재고·납품·휴가 기록을 함께 제공합니다.
- 작성자는 이름 / 부서 / 직급으로 표시됩니다.
- 관련 문서를 추천하거나 연결하는 링크가 없습니다.
- 증거 보관함과 개인 메모는 없습니다. 사용자가 별도로 정리하며 진행합니다.
- 최종 보고서는 인물과 20자 이상의 사건 설명만 작성합니다. 문서 번호와 필수 키워드는 검사하지 않습니다.
- 로그인 상태는 메인 홈페이지로 돌아가도 유지됩니다. 로그아웃하면 해제됩니다.
- 로그인·열람 이력은 현재 브라우저에 저장됩니다. 서버 동기화는 없습니다.
- 거래처 확인 요청과 이메일 발송은 허구의 게임 기능입니다. 실제 외부 전송은 없습니다.
- 게임 내부 로그인은 역할 연출이며 실제 보안 계정이 아닙니다.

## 인수인계와 문서 열람
기존 인수인계 문서를 통해 업무 자료를 확인합니다. 점검 미션과 완료 후 검수 회신은 제공하지 않습니다. 내부 문서는 새 탭으로 열립니다. 서해준·문정우 대화와 개작계약서, 간소화한 보고서는 유지합니다.

## 서사 일관성
0217은 경품 응모가 아닌 원고 출처 이의 제기입니다. 인용 단락은 공개 소개에서 제외하고 2014년 원고와 4월 30일 내부 최종회 교정본에서 대조합니다. 자료 보존 요청은 5월 20일 기준이며, 발송물은 미출간 단행본이 아닌 공개 연재 소책자입니다. 운영자 검토 기록과 수사 확인 사실은 구분합니다.

메일 상단에 같은 대화의 원문·답장·전달본을 시간순으로 표시합니다. 제목 유사도 대신 명시적인 대화 그룹을 사용하며, 열람 권한이 없는 회신은 표시하지 않습니다.

## 거래처 메일 작성
핵심 선행 자료 19건의 개별 열람 후 협업 업체 4곳 중 수신처를 선택해 메일 작성 창을 엽니다. 임의의 일반 키 입력마다 지정 본문이 한 글자씩 표시되고 본문 완성 후 발송할 수 있습니다. 실제 외부 전송은 하지 않으며, 발신 사본과 업체별 회신은 브라우저에 보관합니다. 다온차 발송 시에만 공급 확인 회신이 열립니다.
